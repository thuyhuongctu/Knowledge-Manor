## Tiếng Việt

*Trang viên tri thức* là khung cảnh 3D tương tác về khu trang viên của một nghiên cứu sinh ở đồng bằng sông Cửu Long. Trang chạy hoàn toàn trong trình duyệt, không gửi yêu cầu mạng nào. Công trình đã đổi tên thành **Le Domaine de Hương** và được phát triển tiếp ở một repo riêng:

| | |
| --- | --- |
| **Trang chạy** | <https://domaine.jemappellehuong.com/> |
| **Mã nguồn** | [thuyhuongctu/Le-Domaine-de-Huong](https://github.com/thuyhuongctu/Le-Domaine-de-Huong) |
| **Trích dẫn (DOI)** | [10.5281/zenodo.23539409](https://doi.org/10.5281/zenodo.23539409) |

Repo này chỉ còn một trang chuyển hướng. Ai mở địa chỉ cũ `thuyhuongctu.github.io/Knowledge-Manor/` sẽ tự được đưa tới trang mới, kể cả khi đường dẫn có thêm tham số.

## English

*Knowledge Manor* is an interactive 3D scene of a doctoral researcher's estate in the Mekong Delta. It runs entirely in the browser and makes no network request. The work has been renamed **Le Domaine de Hương** and is maintained in its own repository:

| | |
| --- | --- |
| **Live scene** | <https://domaine.jemappellehuong.com/> |
| **Source code** | [thuyhuongctu/Le-Domaine-de-Huong](https://github.com/thuyhuongctu/Le-Domaine-de-Huong) |
| **Citation (DOI)** | [10.5281/zenodo.23539409](https://doi.org/10.5281/zenodo.23539409) |

This repository now holds only a redirect page. The old address `thuyhuongctu.github.io/Knowledge-Manor/` forwards to the new site, including any query string.
